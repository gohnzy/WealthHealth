# HRnet

Welcome to HRnet! This is our company's internal application to create and view employee records.

## NEW REACT VERSION

To launch it, use 'cd react-version' in command line when in this directory then use 'npm start' to launch the React App !

### JQuery's dropdown menu plugin replaced by ReactJS package

You can find the new package for dropdown menu (select input) on NPM : [select-menu-react-plugin](https://www.npmjs.com/package/select-menu-react-plugin)
From v 2.0.0, package is in TypeScript, compiled in a regular JS file with Babel.
If you want to use pure JS version, install v 1.2.1 of this package instead
